• Voice commands go mic → AssemblyAI STT → wake-word/intent router → /api/describe or /api/meds → speaker. Medicine answers are assembled in meds.js from copied label text, so nothing unprinted is spoken.
  • Guide mode is the same live loop with a goal set: a directive about every 1.5 s, until the arrival check passes.
  • Android is a thin Capacitor shell that loads the UI from the server (adb reverse in testing), so keys never ship in the APK.
